SVVR Backups: privacy and data handling

SVVR Backups is an administrator-operated recovery utility for the SVVR reporting bot.

Google Drive access

The application requests the drive.file permission to create, read, list, and rotate backup files it creates in the authorized owner's Google Drive. It does not request access to unrelated Drive files. It does not modify the operational Google Sheets used by the reporting bot.

Backup contents and encryption

Recovery copies contain the reporting bot's SQLite database, configuration and credentials, source files, and unfinished report or feedback files. These copies can contain user identifiers and submitted text. Cloud copies are encrypted by restic before upload. The repository password is kept separately from the cloud repository. Authorization credentials are stored in restricted server configuration.

Storage and use

Google Drive data is used solely to store and recover these backups. It is not sold, used for advertising, or sent to AI services by this backup utility. The configured retention policy keeps 24 hourly, 30 daily, 8 weekly, and 12 monthly recovery points, with seven days of local server archives. History accumulates while backups run.

Control and deletion

The authorized account owner can revoke the application's access in Google Account settings and delete its backup folder from Drive. The administrator can also delete local backup archives and the backup configuration. Revoking authorization stops future cloud backups; it does not itself delete existing files.

Contact

For access, recovery, or deletion requests, contact the administrator who provided the SVVR bot and configured this backup integration.
